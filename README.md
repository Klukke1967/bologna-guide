# Bologna & Omegn Guide

Static PWA for Bologna and Emilia-Romagna.

## Deploy to Vercel

1. Import this folder as a Vercel project.
2. Keep the root directory as-is.
3. Use the default static deployment.
4. Add the custom domain `bologna.vinverdenerundt.dk` in Vercel after deployment.

## Local preview

Serve the folder with any static server and open `index.html`.
